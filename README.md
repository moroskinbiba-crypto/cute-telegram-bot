# 💕 Cute Telegram Bot

Небольшой Telegram-бот, который каждые 3 часа отправляет случайное милое сообщение.

## Как это работает

1. Токен бота хранится в GitHub Secrets.
2. GitHub Actions каждые 3 часа проверяет, появился ли получатель.
3. Когда девушка впервые нажимает **Start** / отправляет `/start`, бот получает её чат и автоматически сохраняет его в переменную GitHub Actions.
4. Дальше `chat_id` больше не нужно получать заново — бот использует сохранённого получателя.

Тебе не нужно знать или вручную вводить `chat_id`.

## Настройка токена

В репозитории:

**Settings → Secrets and variables → Actions → New repository secret**

Создай секрет:

- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather

Токен никому не отправляй и не помещай в код.

## Проверка бота

Для проверки Telegram-соединения открой:

**Actions → Test Telegram bot → Run workflow**

Этот тест проверяет токен и доступ к Telegram API, но не отправляет сообщение получателю.

## Перед первым получателем

Ничего заранее вводить не нужно. Бот уже подготовлен и ждёт первый `/start`.

Когда девушка:

- откроет бота;
- нажмёт **Start** или отправит `/start`;

следующий запуск `Send cute message` найдёт её чат, сохранит его в GitHub Actions и отправит первое сообщение.

## Расписание

Основной workflow находится в:

`.github/workflows/send-message.yml`

Сейчас сообщения отправляются каждые 3 часа:

```yaml
cron: "0 */3 * * *"
```

Например, каждые 2 часа:

```yaml
cron: "0 */2 * * *"
```

GitHub Actions запускает scheduled workflows по UTC и может запускать их с небольшой задержкой.

## Свои сообщения

Список сообщений находится в `bot.py`, внутри `MESSAGES`.
