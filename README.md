# 💕 Cute Telegram Bot

Полностью автоматический Telegram-бот на **Cloudflare Workers**.

Пользователь один раз нажимает `/start`, после чего бот:

- сохраняет пользователя в Durable Object;
- показывает две кнопки: **«⏰ Поменять частоту»** и **«💌 Получить сейчас»**;
- автоматически присылает милые сообщения;
- позволяет выбрать частоту **30 минут / 1 час / 3 часа**;
- продолжает работать без запущенного компьютера и без постоянных запусков GitHub Actions.

## Архитектура

```
Telegram
   ↓ webhook
Cloudflare Worker
   ↓
Durable Object (подписчики + настройки)
   ↓
Cron Trigger каждые 30 минут
   ↓
проверка, кому уже пора отправлять сообщение
```

GitHub Actions используется только для автоматического деплоя кода в Cloudflare.

## Поведение

### Первый запуск

Пользователь отправляет:

`/start`

Бот регистрирует её и показывает меню.

Повторно нажимать `/start` не нужно.

### Кнопки

**⏰ Поменять частоту**

Показывает:

- 30 минут
- 1 час
- 3 часа

После выбора начинается новый отсчёт до следующего автоматического сообщения.

**💌 Получить сейчас**

Сразу отправляет милое сообщение.

### Команды

`/start` — подписаться и открыть меню.

`/now` — получить сообщение сразу.

`/stop` — отписаться.

Обычное личное сообщение тоже регистрирует пользователя и получает ответ.

После `/stop` старые кнопки не могут случайно подписать пользователя обратно — для повторной подписки нужно снова отправить `/start`.

## Расписание

Cloudflare Cron запускается каждые 30 минут:

`*/30 * * * *`

Это не означает, что сообщение отправляется каждые 30 минут всем подряд.

Cron только проверяет, кому уже наступило время. Например:

- частота 30 минут → сообщение примерно раз в 30–60 минут;
- частота 1 час → примерно раз в 1–1,5 часа;
- частота 3 часа → примерно раз в 3–3,5 часа.

Небольшой запас появляется из-за того, что Cron проверяет пользователей каждые 30 минут.

## Состояние пользователя

Для каждого подписчика хранятся:

- факт подписки;
- выбранная частота;
- время последней автоматической отправки.

При первой подписке отсчёт начинается с момента регистрации.

При смене частоты отсчёт начинается заново.

## Обработка блокировки

Если Telegram возвращает ошибку `403` при отправке сообщения, пользователь автоматически удаляется из списка подписчиков.

## Деплой

В GitHub Secrets должны находиться:

- `TELEGRAM_BOT_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`
- `CLOUDFLARE_API_TOKEN`

После push в `main` GitHub Actions автоматически:

1. устанавливает закреплённую версию Wrangler;
2. проверяет синтаксис Worker;
3. загружает Telegram token в Cloudflare;
4. деплоит Worker;
5. обновляет Telegram webhook;
6. проверяет `/health`.

Постоянно держать GitHub Actions или компьютер запущенными не требуется.

## Безопасность

Telegram token не хранится в исходном коде.

Webhook получает секрет, который Worker хранит внутри Durable Object.

Не передавайте Telegram token в чат, README, commit или исходный код.
