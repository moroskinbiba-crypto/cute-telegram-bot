# 💕 Cute Telegram Bot

Небольшой Telegram-бот, который каждые 3 часа отправляет случайное милое сообщение.

## Настройка

### 1. Добавь токен

В репозитории открой:

**Settings → Secrets and variables → Actions → New repository secret**

Создай секрет:

- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather

Больше никаких секретов для чата не нужно.

### 2. Передай боту получателя

Девушка просто открывает бота в Telegram и нажимает **Start** или отправляет:

`/start`

Бот сам увидит этот чат при следующем запуске GitHub Actions. Никакой `chat_id` тебе узнавать не нужно.

### 3. Первый запуск

Чтобы сообщение пришло сразу, открой:

**Actions → Send cute message → Run workflow**

Если пользователь уже отправил боту `/start`, бот найдёт этот чат и отправит первое милое сообщение.

После этого workflow будет запускаться автоматически каждые 3 часа.

### Важно

Бот получает сообщения через Telegram `getUpdates`. Поэтому после `/start` не удаляй сообщение до первого запуска workflow.

## Изменить частоту

Расписание находится в:

`.github/workflows/send-message.yml`

Сейчас:

```yaml
cron: "0 */3 * * *"
```

Это запуск каждые 3 часа.

Например, каждые 2 часа:

```yaml
cron: "0 */2 * * *"
```

GitHub Actions может запускать scheduled workflow с небольшой задержкой.

## Добавить свои сообщения

Список сообщений находится в `bot.py`, внутри `MESSAGES`.
